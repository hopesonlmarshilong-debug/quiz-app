# QuizRank Online Quiz & Leaderboard System

## Project Overview

QuizRank is a frontend quiz application developed using HTML, CSS, and JavaScript. The system allows users to register, log in, answer quiz questions, view their scores, and compete on a leaderboard.

The application is fully responsive and works on desktop and mobile devices.

---

## Features

- User Registration
- User Login
- 15 Multiple Choice Questions
- Timer for Each Question
- Score Calculation
- Results Display
- Leaderboard System
- Responsive Design
- Mobile Friendly Interface

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open `index.html` using Live Server.
5. Register a new account.
6. Login and start the quiz.
